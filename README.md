# FOLE — A Jornada de Mestre Sivuca

Jogo musical e biográfico em HTML, CSS e JavaScript, feito para navegador e dispositivos móveis.

## Como jogar
- Abra `index.html` em um navegador moderno.
- Toque nas teclas brancas para a melodia e nos botões vermelhos para os baixos.
- Arraste o controle do fole para modular o ar.
- Nos capítulos de improvisação, alterne entre melodia e baixos até completar a barra.
- O progresso é salvo localmente no navegador.

## Publicar com GitHub Pages
1. No repositório, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
4. Aguarde o GitHub Pages publicar o site. O endereço aparecerá nessa mesma página.

## Observações
- O áudio é sintetizado no navegador com Web Audio API; não contém gravações comerciais.
- Cenas e diálogos dramatizados são ficcionais, não citações reais.
- O jogo usa armazenamento local do navegador para salvar a jornada.
